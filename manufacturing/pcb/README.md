# C86 PCB 제작 메모

- CAM ZIP은 C86 4층 패널을 견적에 올릴 때 사용한 설계 원본입니다. 업체가 생성하는 생산 CAM은 DFM 단계에서 별도로 확인하세요.
- 원본 제작 기준은 JLC04161H-3313, USB HS 외층 차동 90Ω, 레퍼런스 L2입니다. 90Ω ±10%는 명목 목표이며 쿠폰 실측 보증값은 업체와 확인하세요.
- BOM/CPL은 R609만 제외한 실장 검토 자료입니다. 동일한 100kΩ 품번을 쓰는 다른 저항은 유지합니다. 실장 수는 패널당 220개입니다.
- 좌우 SWD는 하단 직각 헤더입니다. 양쪽 모두 다섯 리드와 다섯 홀, 1번 핀, 긴 핀이 기판 안쪽을 향하는지 각각 확인하세요.
- 패널에는 양옆 레일과 좌우 사이 분리선이 있습니다. 실장 후 각 하프와 레일을 어떻게 분리할지 DFM에서 확인하세요.
- 베어보드와 실장 자료를 각각 검토하고, 부품 재고나 대체품은 재주문 시점에 다시 확인하세요.
